# 灰冠のギルド — Version 0.7fix4

ブラウザで遊べる、冒険者ギルド経営シミュレーションRPGです。HTML・CSS・JavaScriptのみで構成した静的Webゲームで、ビルドや外部ライブラリは不要です。GitHub Pagesへそのまま配置できます。

## ローカルで起動

### Windows

`start-local.bat` を実行してください。Windows標準のPowerShellを使うため、Pythonは不要です。サーバー応答を確認してからブラウザを開きます。エラー時はウィンドウを閉じず原因を表示します。

### macOS / Linux

任意の静的HTTPサーバーで配信してください。Python 3がある場合の例です（必須ではありません）。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開いてください。ES Modulesを使うため、`index.html` を直接開かずHTTP経由で起動します。

## GitHub Pagesで公開

1. このフォルダの内容をGitHubリポジトリのルートへ配置してpushします。
2. リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、公開するブランチと `/ (root)` を指定します。
3. Pagesが表示するURLを開きます。

ビルド工程はありません。画像とモジュールは相対パスで読み込むため、リポジトリのサブパスでも動作します。

## Version 0.7の追加内容

- ギルド公認ランクがLv.5になると、中盤の長期遠征先「試練の迷宮」が解禁されます。15区画に分岐・行き止まり・危険な近道を設け、3・6・9・12区画で野営します。挑戦目安はLv.15以上です。
- 迷宮内ではこれまでの罠、毒、飛行敵、崩落、重量負荷、夜襲が組み合わさります。分岐は遠征方針・性格・職業を見て冒険者自身が選び、プレイヤーは遠征中に介入できません。
- 既存4地域に、調査を重ねると遭遇しやすくなる特殊個体を追加しました。討伐すると固有の刻印片を確定で持ち帰ります。刻印片は用途判明前は曖昧な記録で扱われ、売却・納品・維持費補填では失われません。
- 試練の迷宮の最深部には、初回到達時に封印された扉が現れます。4地域で得た刻印片を集めると恒久的に開放でき、推奨討伐水準Lv.20以上の守護者へ挑戦できます。
- 守護者を倒して帰還した隊員には、職業・性格・戦闘での働きから個別の二つ名と自動発動型スキルが与えられます。冒険者詳細とギルドの討伐記録に恒久保存されます。
- セーブ形式を更新し、旧セーブを引き継ぐ際に不足する迷宮・称号・調査データを補います。

## Version 0.6までの機能

- 冒険者には全員ポートレートが割り当てられます。初期6人は共通の画像シートを使い、新しい募集候補には初期イラストと同じアニメ調の専用ポートレートを割り当てます。髪・肌・服の色は2Dスプライトの外見にも反映されます。
- ギルド倉庫では武器・防具・素材などを分類して確認できます。同名・同性能の在庫は数量表示になり、複数個をまとめて売却・納品できます。装備中の品は操作できません。
- 素材は町の工房で簡易装備と交換できるほか、売却や国への納品にも使えます。
- 画面上部に金庫残高・ギルドランク・次回維持費が表示され、倉庫では直近の収支履歴も確認できます。
- 武器種・防具重量を職業適性と照合し、装備不向き時の攻撃・速度低下と遠征後疲労を計算します。装備画面では適性と重量負担を比較できます。
- 旅の背景を既存ポートレートの絵画調アニメ表現に合わせ、ギルド本部、4遠征先、4野営地へ割り当てました。ギルド背景は成長後に少し整った内装へ変わります。
- ギルドレベルが上がると、長距離行軍や追加の危険が遠征に混ざります。数値を上げるだけでなく、疲労・罠・地形の複合を増やします。
- 野営中は遠征方針、疲労、戦利品、見張り役、名声を基に夜盗・山賊・暗殺ギルドの襲撃を自律判定します。観察中は戦闘の行動を見られ、別班を見ていた場合も帰還後に襲撃概要と確認済みの外部脅威が残ります。

## 遊び方

1. 「編成と準備」でパーティーを最大人数まで選び、リーダーと遠征方針を決めます。開始時の上限は3人です。
2. 未調査の遠征先では内部状況は不明です。確認できるのは、帰還した遠征で冒険者が実際に見聞きした事実だけです。
3. 出発後は探索と戦闘が自動で進みます。通常地域では第2・第4階層、試練の迷宮では第3・第6・第9・第12区画で野営します。
4. 募集では候補3人から1人を採用します。採用しなかった候補は去り、次の募集には数日かかります。ギルドランクで登録可能になった職業も候補に出ますが、毎回必ず現れるわけではありません。
5. 帰還報告では戦利品ごとに「保管」「装備」「売却」「国へ納品」を決めます。売却益は装備購入に使い、納品ポイントはギルド昇格と解禁に使います。
6. 冒険者一覧で個人ごとに休養・訓練・軽依頼を選べます。行動ごとに1日が進み、他の冒険者も体調や性格に応じた活動を行います。履歴には結果の概要が残ります。
7. 遠征準備では「観察使い魔」の同行先を1組だけ選びます。主遠征隊を選べば探索と戦闘を詳しく見られます。別班や「同行なし」を選ぶと、主遠征隊の細部は後から再生できません。
8. 10日ごとにギルド維持費を支払います。資金が足りない場合は倉庫品が換金され、冒険者のギルドへの信頼に影響します。信頼を失い切った冒険者は永久にギルドを去ります。
9. 古びた洞窟で新人を育て、準備を整えて新しい遠征先へ向かいます。試練の迷宮は長期遠征です。主遠征隊を観察しなかった場合、調査記録には帰還時に確認できる概要だけが残ります。
10. 戦闘・探索・野営・訓練・軽依頼の観察では、顔ポートレートと共通の外見データから描画する小型2Dキャラクターが動きます。野営では会話相手の関係性に応じて座る距離が変わります。

## 調査記録

ギルド管理画面に、許可を得た遠征先の調査記録が表示されます。敵、危険、状態異常、環境、実際に効果を確認した技能や装備、戦利品などの欄は、まだ経験していない場合「不明」のままです。

国への納品でギルド公認ランクが上がり、人材登録や遠征許可が更新されることがあります。先の解禁内容は一覧表示されません。パーティー上限など、現在有効な権限はギルド管理画面で確認できます。職業や遠征先は必須条件ではありませんが、準備の違いは被害や持ち帰れる戦利品に表れます。

セーブはブラウザの `localStorage` に自動保存されます。既存のセーブキーを維持し、Version 0.7以前のデータもVersion 0.7fix形式へ移行します。サイドバーから手動セーブとニューゲームも利用できます。

## 構成

- `assets/characters/` — 初期ポートレートシートと重複しない募集者ポートレート素材
- `src/data/` — 冒険者、職業、外見差分、装備、ダンジョン、レアボス、二つ名・スキル、野営会話のデータ
- `src/systems/` — 自動戦闘、遠征、封印・二つ名、ギルド成長、募集、日数・自律活動・維持費、関係性、セーブ
- `assets/backgrounds/` — ギルド・遠征先・野営地・試練の迷宮専用の背景
- `src/data/backgrounds.js` — 画面と背景アトラスの対応
- `src/systems/equipment.js` — 職業ごとの装備適性と重量効果
- `src/ui/` — 画面表示、共通ポートレート、Canvas 2Dスプライト描画、野営風景、追加UI
- `src/main.js` — 画面操作と各システムの接続

オンライン機能、複数パーティー同時遠征、クラフト、装備強化、永久死亡は含みません。
